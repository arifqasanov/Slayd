Əməli yaddaşın və prosessorun monitorinqi

Kompüterin ürəyi və yaddaşı necə izlənilir?

Hazırladı: Arif Həsənov

Qrup: 6526a1

Müəllim: Kamran Əbilov

Keçmək üçün ox düymələrindən, boşluq düyməsindən və ya ekrana toxunuşdan istifadə edin.

Monitorinq nədir və niyə vacibdir?

Monitorinq kompüterin resurslarının, yəni prosessorun, əməli yaddaşın, diskin və şəbəkənin vəziyyətinin davamlı şəkildə izlənilməsi, ölçülməsi və təhlil edilməsi prosesidir. Bu proses sayəsində sistemin hazırda necə işlədiyini görür, gələcəkdə hansı problemlərin yarana biləcəyini əvvəlcədən anlaya bilirik.

Əgər monitorinq aparılmırsa, istifadəçi problemi yalnız proqram donduqda, kompüter qəfildən yavaşladıqda və ya tamamilə söndükdə hiss edir. Halbuki düzgün izləmə zamanı prosessorun həddindən artıq yükləndiyini, yaddaşın tükəndiyini və temperaturun təhlükəli həddə yaxınlaşdığını əvvəlcədən görmək olur.

Sürətin qorunması

Sistemi yavaşladan proqramları tapıb bağlamaq kompüterin əvvəlki sürətini bərpa edir.

Xəbərdarlıq

Həddindən artıq qızma və ya yaddaş çatışmazlığı kritik xətaya çevrilməmiş aşkarlanır.

Düzgün planlama

Ölçmə nəticələri hansı komponentin yenilənməli olduğunu dəqiq göstərir və pul itkisinin qarşısını alır.

Prosessor (CPU) və onun izlənilməsi

Prosessor kompüterin əsas hesablama qurğusudur və proqramların verdiyi bütün əmrləri saniyədə milyardlarla dəfə icra edir. Müasir prosessorlar bir neçə nüvədən ibarətdir və hər nüvə ayrıca tapşırığı yerinə yetirə bildiyi üçün bir neçə işi eyni anda aparmaq mümkün olur.

Prosessorun monitorinqində ən çox yüklənmə faizi, takt tezliyi, temperatur və proseslərin sayı izlənilir. Əgər yüklənmə uzun müddət 90 faizdən yuxarı qalırsa, bu, ya ağır proqramın işlədiyini, ya da arxa planda zərərli prosesin resursları sorduğunu göstərir.

Yadda saxlayın: yüksək temperatur prosessoru qoruyan mexanizmi işə salır və o, öz tezliyini avtomatik azaldır. Bu hal “thermal throttling” adlanır və kompüterin xeyli yavaşlamasına səbəb olur.

Əməli yaddaş (RAM) və onun izlənilməsi

Əməli yaddaş kompüterin müvəqqəti və çox sürətli yaddaşıdır. Hazırda işləyən proqramların və açıq faylların məlumatları prosessorun tez əldə edə bilməsi üçün məhz burada saxlanılır. Kompüter söndürüldükdə RAM-dakı bütün məlumat silinir.

RAM monitorinqində ümumi həcm, istifadə olunan hissə, boş qalan hissə və keş (cache) ayrıca izlənilir. Yaddaş çatışmayanda sistem məlumatı yavaş olan diskdəki mübadilə faylına (swap və ya page file) yazmağa başlayır və bu zaman kompüter hiss olunacaq dərəcədə ləngiyir.

proqramların istifadə etdiyikeşboş

Xüsusi təhlükə “yaddaş sızması”dır (memory leak): proqram işini bitirdikdən sonra tutduğu yaddaşı qaytarmır və RAM zaman keçdikcə dolur.

Əsas göstəricilər canlı şəkildə

Monitorinq alətləri nəticələri rəqəmlərlə və diaqramlarla göstərir. Aşağıdakı nümunədə sağlam işləyən sistemin tipik göstəriciləri təqdim olunur və hər dairə müvafiq resursun nə qədər istifadə edildiyini bildirir.

Monitorinq alətləri

Hər əməliyyat sisteminin özündə hazır alətlər var. Windows-da Task Manager və Resource Monitor, Linux-da top, htop və free, macOS-da isə Activity Monitor istifadə olunur. Bundan başqa HWMonitor, Core Temp və Grafana kimi alətlər daha ətraflı məlumat verir.

Sadə üsul: Windows-da Ctrl + Shift + Esc düymələri ilə Task Manager açılır, “Performance” bölməsində prosessor və yaddaşın qrafikləri real vaxtda görünür, “Processes” bölməsində isə ən çox resurs işlədən proqramı tapmaq olur.

Nəticə və tövsiyələr

prosessorəməli yaddaş

Prosessorun və əməli yaddaşın monitorinqi kompüterin sağlam və sürətli işləməsinin əsas şərtidir. Davamlı izləmə sayəsində problemlər yaranmamış aşkarlanır, resurslar düzgün bölüşdürülür və cihazın ömrü uzanır.

Müntəzəm yoxlayın

Sistem yavaşlayanda ilk növbədə Task Manager-ə baxıb ən çox resurs işlədən prosesi müəyyən edin.

Lazımsızı bağlayın

Açılışda başlayan və arxa planda işləyən artıq proqramları söndürmək resursları azad edir.

Təmiz saxlayın

Soyuducunu tozdan təmizləmək və sistemi yeniləmək temperaturu və yüklənməni azaldır.
